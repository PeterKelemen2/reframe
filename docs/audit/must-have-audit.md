# Must-have audit for v1

The M10 release checklist item "Every Must-have for v1 item in `docs/plan/01-scope.md` is
checked off against its demo" ([08 §Release checklist](../plan/08-roadmap.md#release-checklist)).

Scope: every row of the parity table and every bullet of "Must-have for v1" in
[01-scope.md](../plan/01-scope.md#feature-parity-baseline-handbrake), split into items with one
behaviour each, with the wording of [03-features.md](../plan/03-features.md) and
[04-batch-mode.md](../plan/04-batch-mode.md). Branch `m10-hardening`, Linux (AMD RX 7600).

Results: **pass** · **fail** · **partial** · **not checkable** (needs hardware or Windows) ·
**unsure**. Each result has evidence: the command or test id and its real output.

Fixtures are `testdata/media/<name>` (made by `scripts/make-testdata.py`). "Source" names the
plan file and section; "01 parity" is the parity table of 01-scope.md, "01 MH" a Must-have
bullet.

## Summary

Audited 2026-11-18 on `m10-hardening` (item list `cd1a2fb6`, first-pass results `a9311aa2`),
with the pinned FFmpeg n9.0.2 from `.tools/` first on `PATH` and isolated Reframe folders.

**Method.** Four Sonnet auditors (one per area) ran every row. Two Opus verifiers then re-ran
from scratch, with the first results only as claims to check: V1 for areas A and C (77 rows),
V2 for areas B and D (30 rows). They re-ran every non-pass, every pass on the domain-heavy rows
(role detection, HDR and tone mapping, audio defaults, track mapping and relaxation,
apply-to-group, metadata edit and remux, encoder fallbacks, multi-frame crop check) and a
seeded random third of the other passes. The lead reproduced each disagreement. The
"Verified" column says who checked each row.

## Findings outside the rows

These are not row verdicts. Nothing was fixed.

**Product behaviour**

1. Edits are lost when you switch sources. Change the quality of one open file, click another
   source, click back: the job is drafted again from the preset, and a manually added audio
   track is gone. Only queued jobs keep edits. *Ctrl+O* on a second file adds it to the sources
   panel but keeps the previous job in the editor, so *Add to queue* adds the old job again
   (V2 queued one file four times this way; the copies failed as `queue.output_claimed`).
2. `reframe encode DIR -r` re-encodes its own earlier outputs as new sources (`one (1).mp4`).
   `reframe batch` leaves them out.
3. `reframe queue log <id> | head` ends with "unexpected error (BrokenPipeError …) Please report
   this", exit 120.
4. Short CLI commands sometimes print `encoder detection: no help for aac (ffmpeg -h encoder=aac
   exited with code None)` when they end while detection still runs.
5. The web API accepts `when_done: quit` in web mode (200), although the UI disables it.
6. *Turbo first pass* is ignored without a note for SVT-AV1 and VP9. The zscale tone-mapping
   fallback has no BT.2390 (`filter.tune_unknown`) and no peak detection.
7. Right after a cancel, the next job ran a few seconds without a sleep inhibit.
8. A group that spans two seasons (S01 + S02 at loose matching) is named "Anime Show S01".
9. A lint message on an AAC rule with mixdown "keep" says "AAC Mono goes up to 256 kb/s",
   although no track is mono.
10. A draft whose output is in the read-only media root gets two errors for one cause
    (`output.not_writable` and `output.folder_required`).
11. `desktop/packaging/linux/build.sh` exits 1 on the dev version (`invalid version
    "0.1.0-dev.0"` at the rpm step) after it writes the deb (known, 0079). No AppImage was
    built in this audit.
12. The documented notices command in `docs/deployment.md` (`uv run --python 3.14.8 …`)
    recreates the project's `.venv`.
13. Definition details: the x264 `rc-lookahead` table has no ultrafast/superfast value; an
    option the preset sets to its default value (x265 `rd`=4 at slow) is shown and counted as
    "changed"; the advanced panel has no "Basic" category from the 03 sketch.
14. A vitest test (`PresetPicker.test.ts` "opens the presets view at the job's preset") failed
    once under load and passed 3/3 alone.
