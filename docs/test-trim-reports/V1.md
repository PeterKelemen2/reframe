## Deleted tests, by reason

### Parametrized cases that add no new branch (one encoder per kind kept)

The three oracle tests compare the validation notes with the C-6 helpers. All encoders go
through the same code; the encoders differ only in data, and the data of the removed ones has
the same shape as a kept one. `test_audio_agreement.py` (not in this area) still checks C-8
against C-7 for aac, ac3, eac3, libopus, flac and libmp3lame.

- `test_mixdown_issues_follow_the_helper`: 252 -> 144. Encoders now `aac`, `ac3`,
  `libmp3lame`, `libopus` (removed: `eac3`, the same mixdowns and max channels as `ac3`;
  `libfdk_aac` and `flac`, the same as `aac`). All requests and all channel counts kept.
- `test_bitrate_issues_follow_the_helper`: 140 -> 100. Encoders `aac` (free range), `ac3` and
  `libmp3lame` (fixed steps), `libopus`, `flac` (lossless). Removed `eac3` (fixed steps, like
  `ac3`) and `libfdk_aac` (free range, like `aac`).
- `test_samplerate_issues_follow_the_helper`: 42 -> 30. The same five encoders; removed `eac3`
  (the same rate list as `ac3`) and `libfdk_aac` (like `aac`).

### Duplicates

- `test_audio_codes_are_info`: `test_texts_say_what_is_written` asserts `Severity.INFO` for a
  case of each of the five audio codes, and `test_rules` asserts INFO for each code as well.
- `test_bitrates_snap_down_as_handbrake[5.1-6-700-640]`: the same scenario and value as the
  texts case "AC-3 has no 700 kb/s for 5.1 … written at 640 kb/s". The other three values of
  decision 0025 stay.
- `test_rules.py` cases (positive + negative each, 10 tests). The positive scenario is a case
  of `test_texts_say_what_is_written`, which also goes through `scenario.check` (each fix
  applied removes the issue) and asserts the exact message. The negative is a combination the
  mixdown/bitrate oracle checks has no note. The rule (`mixdowns`, `bitrates`) and each of its
  codes keep their other positive and negative cases ("mixdown unsupported", "mixdown would
  upmix", "bitrate above the range", "bitrate not a fixed step").
  - "source layout unsupported" (AC-3 keeps 7.1): texts case "AC-3 cannot keep 7.1".
  - "MP3 cannot keep 5.1": texts case "MP3 cannot keep 5.1(side)".
  - "Dolby Pro Logic II of a stereo source": texts case "Dolby Pro Logic II needs a surround
    source".
  - "upmix to a layout MP3 cannot make": texts case "No upmix: … 3 channels (3.0) … written as
    Stereo".
  - "bitrate below the range of the kept layout": texts case "AAC has no 96 kb/s for 5.1".
