## What you can run today

```sh
uv run reframe probe FILE            # every track: codec, channels, bitrate + source, language, title, roles, flags
uv run reframe probe --json FILE     # the MediaSource model as JSON
uv run reframe encoders              # encoder statuses: the cached result at once, then the re-check
uv run reframe plan FILE [--preset NAME] [-o OUT]       # the issues, then the FFmpeg command
uv run reframe encode FILE|DIR… [--preset NAME] [-o OUT] [-r]   # one job per media file, progress and ETA
uv run reframe name PATH… [--template T]                # name source, parsed fields, output name
uv run reframe batch DIR… [--preset NAME] [--level L] [--dry-run] [-r] [--json]   # season mode: groups, the resolution matrix, encode
uv run python -m reframe.tools       # which ffmpeg / ffprobe / mkvpropedit / mediainfo is used, and why
uv run reframe tools status [--json]   # the same, plus the fetched build; exit 4 without ffmpeg / ffprobe
uv run reframe tools fetch [--build NAME] [--platform P]   # the pinned FFmpeg into <data dir>/tools/ffmpeg (checked; the bundled build)
uv run reframe presets list [--json]   # built-in and user presets, * = default
uv run reframe presets export [NAME…] [-o FILE]   # no names: every user preset
uv run reframe presets import FILE|- [--on-conflict rename|replace|skip]   # - reads stdin
uv run python scripts/make-testdata.py
uv run --no-project python scripts/fetch-tools.py
uv run pytest                        # about 7 000 tests (26 more with -m needs_gpu)
uv run reframe-server --mode web --auth token --media-root DIR --output-root DIR   # the API on loopback; docs at /api/docs
scripts/gen-api.sh [--check]         # OpenAPI → frontend/src/api/schema.d.ts (--check: fail on a diff)
cd frontend && npm run dev:web       # placeholder page only
```

The default preset is *H.265 MKV 1080p*. Without `-o`, the output name comes from the naming
template, next to the source. The queue is saved in `<data dir>/queue.sqlite3`; one Reframe
process owns it at a time, and a second process runs its jobs in a private queue
([0027](decisions/0027-one-process-owns-the-queue-store.md)). Decision
[0042](decisions/0042-one-scheduler-process-and-cli-clients.md) (accepted 2026-10-19) changes
that in M3b: a CLI hands its jobs to the owning server (C-17, S-7). Not built yet.

## Questions for the user that are still open

Each is built with a default that is easy to change. M2 and the core-complete work did not stop
for them.

- **Audio**:
  - an explicit bitrate the encoder cannot do goes **down** to the next allowed step, as in
    HandBrake ([0025](decisions/0025-audio-bitrate-snaps-down.md)), not to the nearest;
  - when a rule keeps the source rate but the encoder lacks it (Opus from 44.1 kHz), the
    codec rules put the snapped rate (48 kHz) into the track with a note; validation shows no
    note for a "same as source" rate ([0019](decisions/0019-audio-codec-rule-details.md),
    [0014](decisions/0014-validation-rules-and-severities.md) follow-ups);
  - a kept 3- to 5-channel layout uses the 5.1 bitrate table;
  - a source with an unknown channel count gets the requested layout (it can be an upmix when
    the probe could not read the channels).
- **C-7** ([0013](decisions/0013-command-builder-details.md)): bitmap burn-in with a crop is
  aligned to the bottom; loudnorm uses TP −1 and LRA 20; "Peak" frame rate makes a VFR source
  constant at the peak rate; DRC 0 turns off FFmpeg's default AC-3 DRC; a passthru track with
  no encoder falls back to AAC; a remux may convert text subtitles; `align_av_start` is
  ignored; chapters of a range that starts or ends on a chapter edge are written as
  FFMETADATA (FFmpeg's copy leaves an empty chapter there).
- **C-8** ([0014](decisions/0014-validation-rules-and-severities.md)): the provisional
  severities (range end beyond the source, lost flags, disk space, forced-only); a per-job
  overwrite flag for the collision setting `ask`; `encoder.option_unknown` is an error, so a
  typed option is never dropped without a word ([0026](decisions/0026-builder-and-validation-agree.md));
  `output.name_not_portable` is a warning on Linux and macOS.
- **C-11** ([0016](decisions/0016-queue-and-job-runner.md)): `close()` ends running jobs as
  `interrupted`; the collision setting `ask` keeps the finished `.part`; a paused job keeps its
  slot; `cancel()` with no id also cancels waiting jobs; the stall watchdog fires after
  10 minutes with no progress, no output and under 5 % CPU, and `mkvpropedit` has 5 minutes; a
  silent track shorter than 3 s fails a loudness-normalised encode (FFmpeg refuses it).
  Core-complete ([0037](decisions/0037-when-done-power-actions-and-job-notifications.md)): the
  when-done action also runs when every job failed; the countdown is cancelled when new work
  starts and at close, not when the when-done setting changes; a batch whose last job the user
  cancelled runs no action; job notifications (setting `notifications`) and the `notify`
  action are independent, done and failed jobs get one, cancelled jobs none.
- **C-12** ([0019](decisions/0019-audio-codec-rule-details.md)): items 3 to 7 (no upmix,
  "fits" needs no decode, no max = the encoder's default, extra outputs, first-of-language)
  were accepted by the lead without asking.
- **C-14** ([0022](decisions/0022-linux-sleep-inhibit-mechanism.md)): when the desktop inhibit
  fails but the logind lock works, only a log line is written, no `app.warning`; a malformed
  `DBUS_SESSION_BUS_ADDRESS` counts as a failed session backend. Core-complete
  ([0036](decisions/0036-power-actions.md)): Windows shuts down with `shutdown /s /t 60` after
  Reframe's own 60 s countdown (a second timer; it closes open apps without asking); polkit is
  never asked for a password; Linux sleep is `systemctl suspend`; no fallback for systems with
  elogind and no `systemctl`.
- **C-15** ([0017](decisions/0017-jobs-service-and-cli.md)): when the template name is the
  source file itself, the output becomes `Name (1).ext`; `-o DIR` is refused with several
  files ([0018](decisions/0018-m2-draft-tracks-and-multi-file-encode.md)); `encode` hides info
  issues; validation waits at most 60 s for encoder detection.
- **C-16** ([0012](decisions/0012-output-naming-rules.md)): the `{hdr}` label order, `und`
  tracks left out of `{audio_langs}`, Plex extras folders as generic folders, the folder's
  show name in front of a bare `S01E01`; a byte that is not UTF-8 becomes `�` in an output
  name; format-spec widths are limited to 255.
- **C-9** ([0015](decisions/0015-presets-and-settings-stores.md)): the 64-level nesting limit.
- **C-12 selection stage** ([0031](decisions/0031-audio-and-subtitle-selection-stage.md), the
  points marked "open"): with no language set anywhere, every track is kept in source order (as
  in M2); an undetermined track counts as the first listed language and is written with it;
  `other_languages = keep_first` keeps the best track of the first other language in source
  order; music-only tracks are extra tracks, like commentary and description; the foreign audio
  search track goes first and gets the forced flag; `foreign_audio` burn-in, when the audio is
  not in the viewer's language, burns the first main subtitle in that language; a selected
  track the container cannot hold is not burned in by the defaults (validation offers burn-in or
  MKV); the no-match rule takes only main tracks.
- **C-12 batch engine** ([0040](decisions/0040-batch-engine-and-reframe-batch.md)): the strict
  level compares no bit rate; near members within 2 differences; a relaxed rule does not take
  another rule's exact match; an unchanged track name stays "from the source", an edited one is
  the same in every file; output options are in no *Apply to group* section;
  `detect_per_file` leaves the rectangle empty (the batch runs no crop detection); an existing
  output is a batch error only with *auto-rename*, an output that is a file of the batch with
  every setting; `reframe batch` queues the valid files, lists the others and exits 1; a file of
  the batch that is another file's planned output is left out as already encoded; a per-file
  override cannot add, remove or move track rules or change the rules the defaults compile to.
- **C-10** ([0032](decisions/0032-analysis-scans-and-their-fixtures.md)): a PGS event count
  counts display sets, the "clear" ones too (about twice the number of subtitles); roles are
  worked out again after a scan; a measured loudness is not stored with the source; the DTS-HD
  MA fixture has no core.
- **C-13** ([0034](decisions/0034-metadata-edit-in-place.md)): *Edit in place* with a change
  that needs a remux is an error with a fix, not a silent remux; chapter names and tags other
  than the title are not edited in place; `remux_job` drops the preset's tag overrides and
  chapter renames; an in-place edit keeps the video's flags as they are.
- **C-6 / C-8** ([0035](decisions/0035-advanced-option-sets-and-dry-run.md)): an inactive option
  is a warning, not an error; a parameter that x264 / x265 / SVT-AV1 only log is an error in the
  dry run; the dry run's timeout is 30 s; the dry run tests the video only.
